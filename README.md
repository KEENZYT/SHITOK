# ЩИТОК для iPhone — проект и сборка IPA

Это проект приложения для iPhone и iPad. Оно открывается отдельной иконкой без интерфейса браузера; игра и её файлы находятся внутри приложения, поэтому после установки интернет ей не нужен. Внутри используется встроенный iOS-компонент WKWebView. Версия игры — 38 уровней, включая поиск обрыва. Ориентация: портретная и горизонтальная; для мелких элементов удобнее повернуть телефон.

**Важно: в этом архиве нет готового IPA.** Это исходный проект и автоматическая сборка неподписанного IPA на GitHub Actions. Проект и файл сборки проверены структурно, но Xcode в этой среде нет, поэтому реальную сборку и запуск на iPhone здесь проверить не удалось.

## Как получить неподписанный IPA без своего Mac

1. Распакуйте этот архив. На GitHub создайте репозиторий (можно приватный).
2. Загрузите **содержимое** папки `ios-shchitok` в корень репозитория: рядом должны оказаться `Shchitok.xcodeproj`, папка `Shchitok`, `README.md` и скрытая папка `.github`. Особо проверьте наличие файла `.github/workflows/build-ipa.yml`: без него вкладка Actions не увидит сценарий. Скрытые папки при распаковке или загрузке могут не отображаться; на компьютере включите их отображение.
3. Откройте вкладку **Actions** → **Build unsigned iPhone IPA**. Если потребуется, разрешите Actions для репозитория. Запуск должен начаться после загрузки в ветку `main`; также можно нажать **Run workflow** на вкладке Actions после появления сценария в основной ветке.
4. Дождитесь успешного завершения. Откройте завершённый запуск и в разделе **Artifacts** скачайте `Shchitok-unsigned-iPhone-IPA`. GitHub отдаёт архив с файлом `Shchitok-unsigned.ipa` внутри. Артефакт хранится 14 дней; потом сборку можно запустить снова.
5. Подпишите IPA своим способом с подходящим сертификатом и профилем, затем установите подписанное приложение на iPhone. Неподписанный IPA напрямую на обычном iPhone не запустится.

Если сборка не прошла, откройте журнал конкретного шага в Actions: ошибка Xcode будет там. GitHub может требовать доступной квоты минут для macOS runners.

## Подпись и установка

Для подписи обычно нужны сертификат Apple Development или подходящий дистрибутивный сертификат **с соответствующим закрытым ключом**, а также совместимый provisioning profile. Для обычной разработки профиль должен включать ваш iPhone и подходящий Bundle ID; тип сертификата и профиль должны соответствовать способу установки. Сам по себе API-ключ App Store Connect (`.p8`) не является сертификатом для подписи приложения. Bundle ID в проекте по умолчанию — `com.shchitok.game`; при необходимости используйте свой идентификатор и совместимый профиль в выбранном вами инструменте подписи.

В зависимости от версии iOS и способа установки может понадобиться включить **Developer Mode** в настройках iPhone и подтвердить доверие разработчику. Срок работы приложения зависит от срока сертификата и профиля.

**Никому не отправляйте закрытый ключ, пароль от сертификата, provisioning profile или доступ к Apple ID.** В GitHub этот проект и сборка не требуют секретов Apple — ничего из перечисленного туда загружать не надо. Не используйте непроверенные сервисы подписи для своих ключей.

## Если всё же появится Mac с Xcode

Откройте `Shchitok.xcodeproj`, выберите target `Shchitok` → Signing & Capabilities, укажите свою команду и уникальный Bundle Identifier, подключите iPhone и соберите приложение на устройство. В Xcode можно выбрать автоматическую подпись; Apple ID и настройки подписи остаются у вас.

## Данные и обновления

Рекорды сохраняются локально внутри приложения. Данные из открытой ранее браузерной версии автоматически не переносятся. При удалении приложения его локальные данные могут удалиться. Чтобы обновить игру в проекте, замените четыре файла в `Shchitok/Web/`: `index.html`, `styles.css`, `levels.js`, `game.js` — и соберите приложение заново.

Схемы и прозвонка условны: игра не является инструкцией по работе с настоящим электрощитом.
